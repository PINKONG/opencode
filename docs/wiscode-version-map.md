# WisCode 版本映射

本文档用于记录 **WisCode 对外版本号** 与 **OpenCode upstream 基线版本** 的对应关系。

这两套版本号不是同一个体系，不能直接比较大小：

- `WisCode 1.0.5` 不代表“落后于 OpenCode 0.4”
- 它表示“WisCode fork 后重新定义的产品版本”
- 与此同时，工程同步时仍必须明确它基于哪个 OpenCode tag

## 当前规则

- **对外产品版本**
  用于 DMG、EXE、更新包、发布说明、用户可见版本号

- **上游基线版本**
  用于跟踪当前 WisCode 是从哪个 OpenCode release / tag 演进而来

## 后续维护规则

每次同步 upstream 后，都要同时决定两件事：

1. **是否切换 OpenCode 基线**
   例如从 `v1.4.0` 升到 `v1.4.1`

2. **是否提升 WisCode 对外版本**
   例如从 `1.0.4` 升到 `1.0.5` 或 `1.1.0`

推荐做法：

- 小范围上游同步、无明显对外功能变化：
  `WisCode 1.0.4 -> 1.0.5`
  `OpenCode v1.4.4 -> v1.4.5`

- 有明确的新功能或产品级变化：
  `WisCode 1.0.x -> 1.1.0`
  同时记录对应的 OpenCode 基线

## 发布前检查

每次发布前都应确认：

- `package.json` / Tauri / 桌面构建配置中的 WisCode 版本号正确
- 本文档中的映射已更新
- 发布说明同时写清楚：
  - 本次 WisCode 版本
  - 对应 OpenCode 基线
  - 是否包含上游同步
